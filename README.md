# Zaira Furnishing — Bespoke Interior Atelier & Furnishing Platform

A luxury e-commerce and consultation booking platform built for **Zaira Furnishing**, Hyderabad. Specializing in bespoke curtains, architectural motorized blinds, Italian sofa fabrics, designer wallpapers, artisanal carpets, and premium sleep systems.

---

## 🌟 Key Features

* **WhatsApp-First & Lead-Generation Architecture**: Direct WhatsApp order routing and in-home consultation booking.
* **158+ Complete Static & Dynamic Pages**: Full catalog covering Curtains, Blinds, Sofa Fabrics, Wallpapers, Carpets, Mattresses, Wooden Flooring, and Bed Linen.
* **In-Home Laser Measurement Booking**: Dedicated modal flow capturing room dimensions, fabric demos, and appointment schedules across Hyderabad.
* **Interactive Atelier Buy-Box**: Seamlessly toggling made-to-measure custom fabrication (laser measurements) vs catalog purchase.
* **Admin Dashboard (`/admin`)**: Complete management of products, categories, home visit measurement requests, CMS blocks, and order inquiries.

## 🛠️ Technology Stack

* **Framework**: Next.js 16 (App Router, Turbopack)
* **UI & Styling**: React 19, Tailwind CSS v4, Lucide Icons
* **Database & Storage**: Zero-dependency SQLite / Cloudflare D1 with automatic schema migration & seed data; Cloudflare R2 image pipeline
* **Deployment**: Optimized for Vercel and Cloudflare Pages
